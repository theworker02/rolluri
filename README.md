# rolluri

Roll validation gates for uri inputs before they hit prod.

**Site:** https://theworker02.github.io/rolluri/

## Install / run

```bash
git clone https://github.com/theworker02/rolluri.git
cd rolluri
node src/cli.js
node --test
```
